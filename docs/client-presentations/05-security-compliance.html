Architecture

How machina protects your virtualization infrastructure with defense-in-depth security, strict input validation, and comprehensive audit capabilities.

Authentication

Multi-layered authentication with PAM integration, secure session management, and API token support for automation.

PAM Integration

Authenticate against system users via Linux PAM. Supports local accounts, LDAP, SSSD, and any PAM-compatible identity provider. No separate user database to manage.

Session Management

Secure cookie-based sessions with HttpOnly and SameSite=Strict flags. Sessions cannot be read by JavaScript or sent cross-origin. Automatic expiration and renewal.

API Tokens

Machine-to-machine authentication via mach_-prefixed tokens (32 random bytes as hex; legacy vs_ tokens remain valid until rotated). Tokens can be scoped and revoked independently of user sessions.

Authorization

Role-Based Access Control with three built-in roles. Defaults to the most restrictive role for unknown users.

Admin

Full access to all operations including user management, system configuration, and destructive actions.

Create/Delete VMs Manage Users System Config Backups Migration

Operator

Manage VMs — start, stop, create, snapshot, console access. Cannot manage users or modify system settings.

Create/Delete VMs Start/Stop Console Access Snapshots Manage Users

ReadOnly

View only — list VMs, view metrics, read logs. Cannot modify any resource. This is the default role for unknown users.

List VMs View Metrics Read Logs
Unknown or unauthenticated users default to ReadOnly permissions. The principle of least privilege is enforced at every layer.

Input Validation & Hardening

Every user input is validated, sanitized, and bounded before it reaches libvirt. Defense-in-depth at every layer.

Name Validation

VM, network, and pool names restricted to 1-64 characters. Only alphanumeric, hyphens, underscores, and dots allowed. Rejects empty strings and special characters.

vCPU / Memory / Disk Bounds

vCPU capped at sane limits. Memory bounded between 64 MB and 1 TB. Disk resize capped at 0-10240 GB to prevent f64 overflow and UB.

XML Escaping

All user inputs are XML-escaped before insertion into libvirt domain XML. Prevents XML injection attacks that could alter VM definitions.

Path Canonicalization

ISO paths and file references pass through canonicalize() + is_file() checks. Resolves symlinks and prevents path traversal attacks.

Integer Overflow Protection

All capacity calculations use checked_mul() instead of unchecked arithmetic. Prevents silent overflow that could lead to zero-sized allocations.

SSRF Prevention

Migration URIs validated against an allowlist: qemu://, qemu+ssh://, qemu+tcp://, qemu+tls://, qemu+unix://. Blocks arbitrary URI schemes.

Webhook URL Validation

Webhook destinations restricted to http:// and https:// schemes only. Prevents file://, ftp://, and other protocol abuse.

Email Header Injection

Alert email fields sanitized to prevent CRLF injection. Newlines and carriage returns stripped from all header values.

USB ID Validation

USB vendor and product IDs validated as proper hexadecimal values. Prevents injection of malicious device identifiers via the USB passthrough API.

Network Security

Minimal attack surface with same-origin enforcement, strict path validation, and systemd sandboxing.

Same-Origin Policy

No CORS layer configured. The API only accepts requests from the same origin, preventing cross-site request forgery and unauthorized cross-origin access.

PTY Path Validation

Serial console paths must start with /dev/pts/. Prevents arbitrary file read/write through the console WebSocket endpoint.

SSH Host Validation

SSH connection targets validated before spawning sessions. Prevents SSH to unintended hosts through the browser-based SSH terminal.

Systemd Hardening

The daemon runs with extensive systemd sandboxing directives for defense-in-depth process isolation.

Audit & Monitoring

Complete visibility into every operation with structured audit logs, real-time events, and Prometheus-compatible metrics.

Audit Logging

Every API call is logged with timestamp, user, action, target resource, and result. Structured log format compatible with log aggregation tools (ELK, Loki, Splunk).

Prometheus Metrics

Export host and VM metrics in Prometheus exposition format. CPU, memory, disk I/O, and network throughput per VM. Scrape-ready at /api/metrics/prometheus.

Real-Time WebSocket Events

Live event stream over WebSocket for VM state changes, errors, and system alerts. Powers the web UI dashboard and can feed external monitoring systems.

Destructive Action Safeguards

Toast notifications and confirmation dialogs for destructive operations (delete VM, remove snapshot, wipe storage). Prevents accidental data loss with explicit user confirmation.
