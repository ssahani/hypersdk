The Problem

VM detail used to bury connectivity, NAT, and doctor signals inside a long Overview scroll.

Before

  • Daily access, NAT, and laptop checklist scattered across panels
  • Doctor, XML, and host FS noise on Overview
  • Power actions mixed with navigation chrome
  • No single “connect now” surface

After

  • One Connect hub on Overview + full Access tab
  • Attention stack shows top blocker; chips swap banners
  • Action bar: Cinema, SSH, contextual power
  • Overview keeps live metrics only

Attention

Attention Stack

Show the highest-impact issue expanded; demote the rest to chips.

Priority 1

Pending config shutdown — VM waiting on operator approval before power change.

Priority 2

Guest agent offline — metrics and IP discovery degraded until qemu-guest-agent returns.

Priority 3

Laptop NAT path incomplete — libvirt NAT guest missing expose-SSH or copy command.

Interaction rules

  • Only one banner expanded at a time
  • Click a chip to swap which banner is expanded
  • Guest-agent dismiss persists per VM in localStorage
  • Ask Zeus opens Spotlight with VM blockers via vmDetailSpotlight.ts

  • Full Connect hub with NAT panel expanded
