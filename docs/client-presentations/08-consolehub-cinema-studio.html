Cinema

Cinema Layout

VM canvas fills the viewport; platform chrome hidden for immersive display access.

Hero canvas

  • Sidebar and checklist hidden in Cinema mode
  • Fit / Fill / Native / Scroll / Stretch scale modes
  • Idle-hide control strip (~3.5s); mouse move reveals HUD
  • Screenshot capture from bottom strip

Access Note pill

  • Guest / NAT / SSH warnings collapse to one expandable pill
  • Command palette ⌘K for scoped console actions
  • Studio toggle + Ops Shelf handle on strip
  • Serial-recommended VMs auto-redirect Cinema → Studio

Entry points: VM detail Open Cinema, Machine Finder gallery, Fleet Command Center, Spotlight, Live Preview Wall.

Mode persistence
